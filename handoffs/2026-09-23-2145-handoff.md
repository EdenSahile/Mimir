## Enseignements

- Les slash commands personnalisées vivent dans `~/.claude/commands/` (global) ou `.claude/commands/` (projet), pas dans `skills/`. Le dossier `skills/` est réservé aux plugins installés. Les deux s'invoquent avec `/nom`, mais seuls les skills peuvent se déclencher contextuellement (sans slash).
- La protection de branche GitHub via `gh api` est gratuite uniquement sur les repos publics. Sur un repo privé, il faut un plan Team ou Enterprise.
- Le coût en tokens au démarrage (~20 %) vient principalement du prompt système de Claude Code (instructions, définitions d'outils, skills, MCP servers), pas des rules utilisateur. Réduire les rules fait gagner ~800-900 tokens, ce qui est marginal face aux ~3 millions de tokens système.
