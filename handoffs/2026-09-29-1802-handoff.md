## Enseignements

- Le `@import url(...)` CSS placé après `@import "tailwindcss"` dans `index.css` retardait le chargement des fonts Google. Les déplacer dans `index.html` avec `preconnect` garantit que la connexion au CDN démarre avant le parsing CSS.
- Le rendu conditionnel React (`{condition && <div>}`) empêche toute transition CSS : l'élément est monté/démonté d'un coup, sans fondu possible. Pour des transitions fluides, il faut toujours rendre l'élément et contrôler sa visibilité par `opacity` + `transition`.
